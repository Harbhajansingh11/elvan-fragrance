## Deploy to Vercel (Live in 60 Seconds)

### Method 1: Deploy via GitHub (Recommended)
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **"Add New..."** > **"Project"**.
4. Import your GitHub repository.
5. Leave the framework preset as **Other** (it will automatically detect `index.html`).
6. Click **"Deploy"**. Your luxury website will be live worldwide with SSL and CDN!

### Method 2: Deploy via Vercel CLI
1. Open PowerShell or Terminal in this folder:
   ```bash
   npm i -g vercel
   vercel
   ```
2. Follow the 3 prompts and select defaults.
3. Run `vercel --prod` to deploy to production.
